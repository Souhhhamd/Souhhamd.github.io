## 3) TaskFlow — Application Angular de gestion de tâches

🔗 https://taskflow-gray-gamma.vercel.app/feed  
📂 Code source : *(à ajouter si tu publies le repo GitHub)*

**Contexte :**  
Projet académique développé avec **Angular** visant à concevoir une **Single Page Application (SPA)** permettant aux étudiants d’organiser efficacement leurs tâches.  
L’application intègre un **système de recommandation automatique** basé sur plusieurs critères afin d’identifier la tâche la plus pertinente à réaliser.

**Fonctionnalités principales :**

- Affichage des tâches sous forme de **feed dynamique**
- Filtres par **catégorie**
- Système de **score automatique** pour recommander la tâche prioritaire
- Ajout de tâche via **formulaire réactif avec validation**
- Page de **détail d’une tâche** accessible par routing
- Interaction utilisateur avec **gestes swipe**
- Séparation visuelle entre **tâches à faire** et **tâches terminées**
- Interface **mobile-first inspirée des applications modernes**

**Logique de recommandation :**

Chaque tâche reçoit un **score calculé automatiquement** selon plusieurs critères :

- priorité
- importance
- énergie requise
- proximité de la deadline

La tâche ayant le score le plus élevé reçoit un badge **“recommandée”** afin d’aider l’utilisateur à prioriser son travail.

**Technologies utilisées :**

- Angular 19  
- TypeScript  
- HTML5  
- SCSS  

**Concepts Angular utilisés :**

- Architecture par **composants**
- **Services** et injection de dépendances
- **Reactive Forms**
- **Angular Router** avec paramètres dynamiques
- **Pipes personnalisés**
- Directives (`*ngFor`, `*ngIf`, `ngClass`)
- Communication entre composants (`@Input`, `@Output`)

**Compétences développées :**

- Développement d’une **Single Page Application**
- Structuration d’une application Angular modulaire
- Conception d’une **logique métier (algorithme de scoring)**
- Gestion de formulaires et validation
- Organisation d’un projet front-end structuré
- Conception d’interfaces **mobile-first**
